## 🚀 Instalación y ejecución local

Sigue estos pasos para instalar y ejecutar Puigsounds en tu entorno local:

```bash
git clone https://github.com/mgrl39/puigsounds.git  # Clonar el repositorio
cd puigsounds                                       # Acceder a la carpeta del proyecto
npm install                                         # Instalar dependencias
ionic serve                                         # Ejecutar el proyecto en modo desarrollo
```
